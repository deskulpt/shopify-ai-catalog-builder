# Phase 3 Plan 01: LLM extraction service layer and unit normalization

## Objective

- **What:** Add the AI/LLM extraction backend capability to parse converted Markdown text into structured product fields and normalize industrial specs (e.g. weights, voltages, dimensions).
- **Why:** Enable automatic draft product schema extraction from raw Markdown files and documents without requiring manual data entry.
- **Output:** `/extract` endpoint in the Flask app, standard unit-normalizer rules, and a React Router API proxy route.
