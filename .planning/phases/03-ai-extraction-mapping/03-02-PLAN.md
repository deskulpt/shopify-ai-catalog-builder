# Phase 3 Plan 02: Variant grouping engine and purchase type detection

## Objective

- **What:** Build the variant grouping engine to cluster similar products in a category, and implement quote-only vs. direct-buy detection.
- **Why:** Prevent catalog pollution. Instead of importing 10 separate variants as 10 separate products, group them into 1 parent product with options, and flag if they need RFQ/quotes.
- **Output:** Variant clustering algorithms in Flask `/group-variants`, Node proxy route, and updated selection UI displaying grouped drafts.
