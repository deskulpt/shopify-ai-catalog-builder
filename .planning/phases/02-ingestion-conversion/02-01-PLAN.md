# Phase 2 Plan 01: Drag-and-drop file upload and URL parsing

## Objective

- **What:** Build the UI components for document uploading and URL ingestion, along with backend API proxy routes that communicate with the Python MarkItDown service on port 5005.
- **Why:** Allow the merchant to easily ingest unstructured files and single-page URLs, providing an editable Markdown preview of the parsed content.
- **Output:** Staged file upload interface, URL text field, backend loaders/actions proxying to the Python microservice, and an editable Markdown view.
