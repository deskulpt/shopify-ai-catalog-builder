# Phase 2 Plan 02: Crawler discovery backend and Polaris Category Tree selection UI

## Objective

- **What:** Implement the domain crawler in the Python service to discover category-product hierarchies, and build the Polaris-based Category Tree UI to select scraping targets.
- **Why:** Allow the merchant to crawl bulk vendor product websites, parse site metadata, and select specific categories/products to ingest rather than scraping blindly.
- **Output:** Crawler service endpoint, collapsible tree selection UI, and target list mapping.
