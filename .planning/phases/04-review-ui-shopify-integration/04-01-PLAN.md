# Phase 4 Plan 01: Polaris draft review UI and Shopify GraphQL publishing

## Objective

- **What:** Build the UI to review extracted draft products (specifications, variant matrices, and purchase types) and implement the publishing logic using Shopify GraphQL mutations.
- **Why:** Allow the merchant to review and modify the AI-extracted product data, and publish them directly to their Shopify store catalog with one click.
- **Output:** `shopify.app.toml` metafield configuration, draft review UI drawer/modal, and `api.publish.tsx` route.
